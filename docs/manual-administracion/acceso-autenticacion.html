Acceso a la plataforma y autenticación

Ingresar​

  1. Abrir la URL de la plataforma seguida de /login (Chrome, Edge o Firefox).
  2. Escribir Correo Electrónico y Contraseña.
  3. Clic en Ingresar.
  4. El sistema redirige al panel según el rol. Administrador → /admin.

Pantalla de login.

Proceso completo de inicio de sesión.

Las credenciales las crea otro administrador desde Usuarios y roles. Cada persona debe tener su propio usuario para mantener la trazabilidad de sus acciones.

Errores comunes​

MensajeCausaSolución
"Credenciales incorrectas"Correo o contraseña no coinciden.Revisar tipeo; si persiste, pedir restablecimiento a otro administrador.
Pantalla en blanco / sin respuestaProblema de red o servidor caído.Revisar conexión y reintentar; si continúa, contactar soporte técnico.

Sesión y cierre​

  • La sesión dura 8 horas; luego pide iniciar sesión de nuevo (es normal, no se pierde información guardada).
  • Al recargar la página dentro de ese tiempo, la sesión se mantiene activa.
  • Para salir, usar el botón Cerrar sesión del panel.

Ubicación del botón "Cerrar sesión".

Buenas prácticas​

  • Un usuario por persona; no compartir credenciales.
  • Contraseñas robustas (mínimo 8 caracteres, con letras, números y símbolos).
  • Cerrar sesión en equipos compartidos o públicos.
  • Reportar de inmediato accesos o cambios no reconocidos.
