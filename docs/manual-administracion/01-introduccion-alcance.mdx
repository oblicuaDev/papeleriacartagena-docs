# Introducción y alcance del sistema

## Para quién es este manual

Dirigido a administradores del sistema y coordinadores comerciales (rol **Administrador**). Su objetivo es que puedan operar la plataforma sin depender del equipo de desarrollo.

Este manual **no cubre** la vista del cliente comprador (catálogo, carrito, pedidos). Esa guía está publicada dentro de la app, en `/manual`.

## ¿Qué es la plataforma?

Sistema B2B de proveeduría para pedidos de papelería y suministros de oficina. Las empresas cliente (con una o varias sedes) hacen pedidos recurrentes con precios propios, aprobación interna y seguimiento hasta la entrega.

| Rol                  | Panel       | Función                                     |
| -------------------- | ----------- | ------------------------------------------- |
| **Administrador**    | `/admin`    | Configura todo y supervisa la operación.    |
| **Asesor comercial** | `/asesor`   | Gestiona pedidos de sus empresas asignadas. |
| **Cliente**          | `/cliente`  | Crea y, si aplica, aprueba pedidos.         |
| **Repartidor**       | `/entregas` | Alista, despacha y entrega pedidos.         |

Este manual cubre el **panel de Administrador**.

## Qué se puede hacer desde Administración

- Catálogo de productos y categorías (+ cargas masivas por Excel/CSV).
- Listas de precios por empresa.
- Empresas y sedes (presupuestos, overrides).
- Usuarios: clientes, asesores, repartidores.
- Asignación de asesores comerciales.
- Seguimiento de pedidos en todos sus estados.
- Reportes (CSV/Excel) y órdenes de compra en PDF.
- Dashboard con indicadores de la operación.

## Cómo leer este manual

- **\*** marca un campo obligatorio.
- Rutas como `/admin/seccion` corresponden a la dirección en el navegador.
- Los recuadros grises con "Captura" o "GIF" son placeholders: van donde debe insertarse una captura de pantalla o un GIF animado real, descrito en el texto en cursiva debajo de cada uno.

:::info Material visual pendiente
Las capturas y GIFs de este manual están por grabarse. Reemplaza cada placeholder por el archivo real y actualízalo cada vez que cambie el diseño del panel de administración.
:::
