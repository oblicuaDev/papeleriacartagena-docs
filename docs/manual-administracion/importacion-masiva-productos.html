Importación masiva de productos

Permite cargar o actualizar el catálogo en lote desde un archivo Excel (.xlsx, .xls) o CSV, en lugar de crear productos uno por uno.

Ubicación: botón "Importar Excel" en /admin/catalogo.

Formato del archivo​

Primera hoja, con fila de encabezados (no distingue mayúsculas/espacios):

DatoColumnas aceptadasObligatorio
SKUSKU, Código, Ref, ReferenciaSí
NombreNombre, Name, ProductoSí
CategoríaCategoría, CategorySí (debe existir previamente)
DescripciónDescripción, Description, DescNo
Precio BasePrecio Base, Precio, Price, ValorSí
StockStock, Inventario, CantidadNo (por defecto 0)
UnidadUnidad, UnitNo (por defecto "Unidad")

Unidades válidas: Unidad, Resma, Caja, Paquete, Pliego, Set, Rollo.

:::warning Antes de importar Las categorías del archivo deben existir previamente (ver Administración de categorías) y coincidir en nombre con las registradas. :::

Pasos: Cargar → Previsualizar → Importar​

Proceso completo de importación masiva.

1. Cargar: arrastrar el archivo al área indicada, o seleccionarlo desde el equipo.

Paso 1, carga del archivo.

2. Previsualizar: el sistema muestra las filas válidas (✓) y con error (⚠), con el detalle del problema (por ejemplo, "SKU requerido" o "Categoría no encontrada"). Solo las filas válidas se importan.

Paso 2, tabla de previsualización.

3. Importar: clic en "Importar N producto(s)". Si alguno falla en el servidor (ej. SKU duplicado), se marca con su error y el resto continúa. Al final se muestra el total importado.

Paso 3, pantalla de confirmación.

Errores comunes​

ErrorCausaSolución
"SKU requerido"Celda de SKU vacía.Completar el SKU en el archivo.
"Nombre requerido"Celda de Nombre vacía.Completar el nombre.
"Categoría no encontrada"El texto no coincide con ninguna categoría existente.Verificar ortografía o crearla primero.
"Precio base inválido"Valor no numérico o vacío.Usar solo números ($ y separadores se limpian automáticamente).
Error "API: {motivo}"El servidor rechazó el producto (ej. SKU duplicado).Corregir el dato y reintentar esa fila.

:::tip Buena práctica Para catálogos grandes, divide la importación en lotes de unos cientos de productos y revisa cada previsualización antes de confirmar. :::
