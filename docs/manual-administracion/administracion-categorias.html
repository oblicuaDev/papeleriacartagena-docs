Administración de categorías

Ruta: /admin/centros-de-costos

Las categorías organizan el catálogo (Papel, Escritura, Aseo, Tecnología...) y sirven como filtro y como base para la importación masiva.

Pantalla principal​

Cuadrícula de tarjetas por categoría, con nombre, descripción, estado (Activa/Inactiva), cantidad de productos y acciones: Editar, Categorías relacionadas, Activar/Desactivar, Eliminar.

Vista general de categorías.

Crear una categoría​

  1. Clic en "+ Nueva Categoría".
  2. Nombre* (obligatorio) y Descripción (opcional).
  3. Checkbox "Categoría activa" (activado por defecto).
  4. Clic en "Crear Categoría".

Crear y editar una categoría.

Editar, activar/desactivar o eliminar​

  • Editar: ícono de lápiz → modificar → Guardar Cambios.
  • Activar/Desactivar: ícono de ojo. Oculta la categoría del catálogo sin borrar nada; es la forma recomendada de "retirarla".
  • Eliminar: ícono de papelera → confirmar.

:::warning Restricción No se puede eliminar una categoría con productos asociados. Reasigna esos productos a otra categoría antes de eliminarla. :::

Categorías relacionadas (cross-selling)​

Define qué categorías se sugieren al ver productos de otra (por ejemplo, "Impresión" con "Papel" y "Tóner").

  1. Ícono de enlace en la tarjeta.
  2. Marcar las categorías relacionadas.
  3. Clic en "Guardar".

Modal de categorías relacionadas.

:::tip Buena práctica Relaciona categorías según la lógica real de compra del cliente para mejorar la experiencia y el ticket promedio. :::
